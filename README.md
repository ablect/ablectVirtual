# Ablect Virtual Money

A glossy virtual economy simulator where players start at ₦0, work for every naira, trade real-world assets, and eventually acquire virtual representations of land, homes, businesses and other property.

## V1 currently implemented

- ₦0 starting balance
- Tap-to-work earning loop
- Energy system
- Persistent browser state via localStorage
- Real-world asset catalogue with live simulation price movement
- Buy/hold portfolio
- Virtual Earth/property marketplace
- Wealth/compound calculator
- Portfolio and net-worth views
- Responsive mobile-first interface
- Glassy/glossy dark visual system
- Custom Ablect Virtual Money logo

## Run locally

```bash
npm install
npm run dev
```

## Important product boundary

V1 is a simulation. Balances, trades and property ownership are virtual only. It does not accept deposits, custody funds, promise investment returns, or execute real securities transactions.
